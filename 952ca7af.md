# Integrity

For any software system, integrity is a central non-functional aspect of the
development. It ensure that everything *does what the user expects*.

This is an extremely important aspect of software engineering because most
software failures come from a violation of system integrity.

There are three kinds of integrity within a software system:

## Data integrity

This garantees that the data that the user interacts with is complete, correct
and coherent.

## Behavioral integrity

The sofware behaves the as intended and is free of logical errors.

## Security

The system is able to *restrict* access to its data and functionality to
authorized users only.
