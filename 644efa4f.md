# Thinking template

This template is meant to be used with pen and paper to think some subject out
and solve problems.

## Discovery section

There are five steps to follow. They should be done in order but going back to
check and edit previous steps is useful throughout the process.

* Desired Outcome: Must be clear, ideally measurable.
* Current state: This part is used to understand whether the current challenge
  is a *root* problem or the *symptom* of a greater issue.
* Large steps: This part is used to identify big steps that must be accomplished
  in order to complete the challenge, and "levers" that can be used to help. The
  big steps will be refined in the *planning* section.
* Value assessment: What solving the problem is worth.
* Decision tree: Who is involved and must be taken into account when actuating
  the solution.

## Planning section: Designing the process

This is a much more free-hand part of the system. The goal of this section is to
design a plan to solve the problem/achieve the goal.

This is where using pen and paper becomes extra useful because it allows the
user to create connections and backtrack easily, without being limited by a list
system on a word document.

## Transform into tasks

Once this work has been done, tasks are easier to create and make sense.

A project can be created in the org system. The tasks can be acted upon using
the [Big Daily Three system](241c4ccf).
