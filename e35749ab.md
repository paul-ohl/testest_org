# Pocket Notebook format

## Size

I want to start by trying out a very small notebook that can fit in my pockets,
but I might go with a bigger one if it's too small later, and I can fit it in a
sling bag that will be easy to carry around with me.

## Tools

* A cover?
  * The cover could be used to store the rest of the tools listed below so that
    I don't have to transfer them when changing notebooks
  * I'd like to build it myself out of fabric or leather
* A pen holder?
* Post-its for the [Big Daily Three system](241c4ccf) (I may use something else
  later, or write it straight into the notebook)
* Reminders for the [Thinking template](644efa4f) and the task system
