# Rust match: read wildcard option

In a rust `match`, if you need to use the wildcard result, you can use `ref`
with a variable name instead of `_` to match on the remaining options.

Example:
```rust
let animal = "cat";
match animal {
  "cat" => println!("Maow"),
  "dog" => println!("Woof"),
  ref unknown => panic!("Unknown animal: {}", unknown),
}
```
