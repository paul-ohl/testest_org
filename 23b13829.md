# Pocket notebook

I want to have a notebook on myself at all times, the goal for it is to use it
as a general "inbox".

## Goals

* Mindfulness: Use it instead of a phone for as many tasks as possible
* Memory: [Handwriting is better for memory](bv/tv8w)
* Inbox: It is not meant to be definitive, all useful info will be archived
  somewhere else
* Thinking tool: See [Big Daily Three system](241c4ccf) and [Thinking template](644efa4f)

## Inspirations

* Lila Björn's [Pocket notebook](https://www.youtube.com/watch?v=4BdCS_aQjmo)
* [Maurice Moves' notebook system](dc3d9c03) and [Big Daily Three system](241c4ccf)
