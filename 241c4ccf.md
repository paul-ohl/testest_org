# Big Daily Three system

Source: [Maurice Moves: Big Daily 3 tasks](https://www.youtube.com/watch?v=JPTKnrRW-t8)

The goal of this system is to allow the user to accomplish at least 3 meaningful
tasks every day.

## How

1. In the evening: Choose and write 3 tasks for the next day
2. In the morning: Read the 3 tasks
3. Cross the tasks as they are accomplished throughout the day

## Useful notes

This is not a task management system, use an actual system for that, and pick
tasks from there.

Use paper to write down the tasks, so that it is more tangible and
distraction-free.

When trying to pick up a new habit, write it as one of the tasks continously
until it is no longer relevant to be a task.
