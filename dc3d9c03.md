# Maurice Moves' notebook system

[Discovery & planning sections](https://www.youtube.com/watch?v=KsKlNjHKByY)

## Notes

Maurice uses that system to solve any major or new challenges.

Here, writing with pen and paper is useful because that process is *non-linear*,
and *iterative*.

My personal [Thinking template](644efa4f) is heavily based upon this system.

### Discovery section: Defining the problem

* Desired Outcome: Must be clear, ideally measurable.
* Current state: It is useful to understand whether the current challenge is a
  root issue or the symptom of a greater issue.
* Baseline hit to homerun: This part is used to identify big steps to accomplish
  to complete the challenge, and "levers" that can be used to help. The big
  steps will be refined in the *planning* section.
* Value assessment: What solving the problem is worth.
* Decision tree: Who is involved and must be taken into account when actuating
  the solution.

### Planning section: Designing the process

This is a much more free-hand part of the system. The goal of this section is to
design a plan to solve the problem/achieve the goal.

This is where using pen and paper becomes extra useful because it allows the
user to create connections and backtrack easily, without being limited by a list
system on a word document.

### Execution section: Actually doing the plan

The two sections before can be kept around for reference, and tasks can be
extracted from them. Once the tasks are precise enough, they can be input into a
task managment system, and can be accomplished using the [Big Daily Three system](241c4ccf).
