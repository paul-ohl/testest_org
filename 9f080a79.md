# Candle-making tools

Listed below are both the ingredients and the tools necessary to make DIY
candles.

## Tools

- Thermometer: It's easy to [overheat the wax](423d04c9), which will result in
  poor-quality candles
- Pots for a "Bain marie": To melt the wax, see [Candle-making process](423d04c9)
- Wick holders: This can be as simple as using a toothpick. The goal is to keep
  the wick centered
- Basic safety gear: Goggles and heat gloves
- A Scale: This allows testing mixes with small but precise quantities, then
  multiplying to get the correct values for a bigger batch
- A heat gun: Can be useful to fix occasional mistakes
